كيفاش تخدم هاد السيت (بلا برمجة)
1) روابط الأفلييت: حل الملف links.js وبدل كل "https://YOUR-AFFILIATE-LINK" بالرابط الحقيقي ديال المنتج. تقدر تعدلو مباشرة من GitHub فالتيليفون (أيقونة القلم).
2) قبل النشر: فكل الصفحات كاين USERNAME.github.io/REPO فالـ canonical والـ sitemap.xml. بدلو بالرابط الحقيقي ديالك (Find & Replace). ولا قولي ليا الرابط ونرجع ليك الملف واجد.
3) النشر: حط الملفات كاملين فـ repo على GitHub، ثم Settings > Pages > Branch: main > Save.
4) الأثمنة والمنتجات: عدلهم حسب اللي كتبيع. الأثمنة الحالية تقريبية للتجربة فقط.
5) ماتكتبش بلي جربتي منتج إلا إلا جربتو فعلا. زيد تصاوير وتجارب حقيقية كل ما قدرتي.
